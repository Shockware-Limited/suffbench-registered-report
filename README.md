# Interfaces or Bodies? A Preregistered Test of ε-Sufficient Context for Language-Model Code Editing in Go

Jude Castiel Johansen, Shockware Limited, independent researcher. ORCID 0009-0002-5644-3073.

Stage 1 protocol of a Registered Report prepared for the MSR 2027 Registered Reports track, archived as DOI 10.5281/zenodo.23307547. No confirmatory data have been collected. The study operationalises ε-sufficient context (definitions note, DOI 10.5281/zenodo.23282195) as a paired non-inferiority test of a compiler-computed interface context against dependency bodies and the transitive slice, with a degradation curve at fixed coverage and an ablation of dependency interfaces.

Pilot verdict records are in `harness/results/`; the Phase 1 to 3 records are in `harness/results-abl/`, `harness/results-p2/`, `harness/results-p2screen/` and `harness/results-p3/`, with every reported number generated by `analysis/phase23.py`. The exploratory report (DOI 10.5281/zenodo.23460566) found, on eleven screened instances from two repositories, that inert padding lowered Haiku 5.5 pass rates where real dependency interfaces did not, that a declaration-level slice of the write-set met the non-inferiority margin only under a post-hoc sample-set choice at about half the tokens, and that single-dependency necessity was non-additive on the one dependency-sensitive instance; no confirmatory claim is made. Instance files under `harness/instances/` carry the author's local checkout paths; `pilot-paper/make_release.py` rewrites them for release.
